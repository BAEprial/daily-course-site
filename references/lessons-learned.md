# 两个已建成站点的经验与踩坑

来源：`python-tutor`（112 天，廖雪峰 Python 教程，端口 8765）与 `mit-600-study`（24 讲，MIT 6.00 / 网易公开课，端口 8766）。以下条目已固化为 `verify_site.py` 的检查项或骨架默认行为，制作新站时不要重新踩一遍。

## 判题与题目

1. **判题看屏幕输出，不看代码文本。** 学员曾因中文全角逗号 `，` 与半角逗号 `,` 连错 5 次；后来又发现早期判题器误判「逗号后必须补空格」，这是错误结论，已收回。文字照抄类题忽略空格差异（`looseSpace`），`'` 与 `"` 等价；计算结果与列表、字典等容器输出仍严格比对。
2. **不超纲。** 第一讲就出现 `CPython/IPython`、`python --version`、`PEP 8` 命名，学员反馈「简介我就看到一堆不懂的东西」。三道题作废移出错题册、不计正确率，原始作答保留。现在统一用 `concepts` 首次出现日 / `unlockDay` 硬过滤，并由自检脚本校验。
3. **术语订正要先做。** 网易公开课中文标题有误译：数组→列表、拉复生方法→牛顿–拉弗森、映射→遮蔽、统计试验模拟→蒙特卡洛；第 5、6 集的「二分法」是求根，第 9 集的「二分法搜索」是有序查找。按误译出题会整批出错，订正写在 `termNotes` 并在课程说明页列出。
4. **文案用结构完整的陈述句。** 不堆碎片短句、不乱用比喻；解析偏短会被自检拦下。
5. **题库源文件与生成物分离。** 改题目必须改 `tools/data/q_*.py`（新框架里是 `data/questions.json`），再跑装配与自检，不直接编辑 `assets/data/questions.js`。
6. **课程事实带核实日期。** 版本、链接、平台状态、开课学期都属易变事实，核实后写 `verifiedAt`，未核实的写「待核实」，不凭印象断言。

## 状态与保存

7. **进度会清零，是因为服务端无脑覆盖。** 前端 `localStorage` 与服务端文件双写时，旧标签页或换浏览器 POST 一份空白状态就会清空进度。修复为服务端按记录身份合并：`attempts` 按 id、`progress.done` 只升不降、`wrongBook` 按 qid、`drafts` 非空优先。
8. **草稿必须实时落盘。** 学员写完费曼复述没点保存，内容丢失，导师看不到，产生信息差。现在文本输入 250ms 防抖自动保存，页面隐藏 / 关闭时 `sendBeacon` 强制同步，并镜像到 `records/drafts.md`。
9. **单一权威源。** `records/state.json` 是唯一事实源；`HANDOFF.md` 是教学上下文；`notes/*.md`、`drafts.md`、`错题册.md` 是派生或镜像。曾出现 `notes/错题册.md` 写「目前没有未掌握的错题」而 `state.json` 里实际有 2 道，原因是多处各写一份「当前进度」。别处只放指针，不复制状态。
10. **交接卡与教学日志。** 每次练习后追加 `teaching-log.md`（append-only），更新 HANDOFF 的当前状态、错题、未结、下一讲；被推翻的结论标「已收回」而不删除。两个站点的 Day 编号与作答记录互不相干，不得混用。

## 启动与工程

11. **`start.bat` 必须是 CRLF 且纯 ASCII。** 2026-11-15 实测：纯 LF 换行 + `chcp 65001` + 中文提示会让 cmd 读取批处理时行错位，`python server.py` 整行被跳过，窗口一闪而过、服务未启动。对照实验显示单独改 CRLF 或单独改纯 ASCII 都能恢复，两者同时采用最稳妥。失败路径必须 `pause` 显示原因，不能静默退出；`python server.py %*` 透传 `--port` / `--no-browser`。
12. **自检固化成脚本，不靠人眼看。** `mit-600-study` 的 `verify.py` 覆盖题量、答案合法性、零超纲、文案完整句、页面引用、服务端临时副本冒烟共 1243 项；`domcheck.js` 在 jsdom 中渲染 7 页并检查答题交互。服务端冒烟必须在临时副本里跑，不触碰真实 `records/`。
13. **生成物不手改。** 页面 HTML、`course.js`、`questions.js` 由 `build_site.py` 生成；手工改完下次装配就会被覆盖。
14. **离线可看、保存需服务。** `file://` 打开页面可以查看，但连不上本地服务，顶栏应显示「离线暂存」。

## 协作与边界

15. **引导式教学。** 先给问题与最小提示，学员尝试后再给参考解答；不代写、不提前抛出未解锁名词。
16. **对外文字只写事实、规格、做法。** 博客、README、简历、项目介绍不夸用户、不把日常小事写成成就、不追加感悟或延展段落；评价与复盘只留在对话和内部记忆。
17. **纯本地、不擅自发布。** 两个站都是 `127.0.0.1` 单机站；新增或修改记录文件不等于发布，未经明确指令不 commit / push、不做在线化或多人同步。
18. **项目之间保持独立。** 端口、Day 编号、状态文件、记忆指针各自独立；给 A 站修 bug 时不要顺手改 B 站，除非用户明确要求。
